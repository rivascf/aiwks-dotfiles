## Code segments

To find a service on Ubuntu, several methods are available, primarily using systemctl for systemd-managed services or service for older init.d services.

1. Using systemctl (Recommended for modern Ubuntu versions):
   List all active services.
   Código

```console
    systemctl list-units --type=service --state=running
```

List all service unit files (regardless of state):

Código

```console
    systemctl list-unit-files --type=service
```

Search for a specific service (e.g., Apache2):

Código

```console
    systemctl list-unit-files --type=service | grep apache2
```

Check the status of a specific service:

Código

```console
    systemctl status service_name.service
```

(Replace service_name with the actual service name, e.g., apache2.service)

2. Using service (for older services or quick status checks):
   List all services and their status.
   Código

```console
    service --status-all
```

(A + indicates running, - indicates stopped, ? indicates unknown status.)

Check the status of a specific service:

Código

```console
    service service_name status
```

3. Examining running processes with ps:

List all running processes and filter for a keyword:

Código

```console
    ps aux | grep keyword
```

(Replace keyword with a relevant term to identify the service, e.g., nginx, mysql)

4. Locating service unit files:

Systemd service unit files are typically found in `/etc/systemd/system/` (for custom services) or `/lib/systemd/system/` (for system-installed services).
You can browse these directories to find service definitions.
